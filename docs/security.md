# Security and Privacy

## Privacy principles

- Process audio in short windows and discard temporary files when no longer needed.
- Prefer storing metadata instead of raw recordings.
- Restrict database access and use secure environment configuration.
- Apply encryption and least-privilege controls where practical.

## Audit trail

The project can optionally maintain a tamper-evident append-only audit log using event hashes and chain linkage.

## Scope note

The prototype does not intercept live cellular calls or private telecom traffic.
